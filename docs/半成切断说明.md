# 半成切断说明(专册)

- 产品:源到达SLA(时限台)
- 缺陷:到达已挂源态未改 —— 入库路(`POST /api/arrivals`)与调度路(`POST /api/catchup/{source}`)各自独立事务读改写 `sources.output_mode`,无同批事务号、无外键绑定、无互斥锁、无争用留痕;后交覆盖先交,到达列表与源目录撕裂且无法对账。
- 复现:`tests/test_half_success.py` 两条失败测(撕裂测、双路抢写测),修复前均已见红。

## 择定(甲乙二选一,不得混用)

**乙路径:到达与源态须同批事务号外键绑定,缺一方则两侧拒收,正式保持撕裂前。**

- 每次入库/调度写:单事务内先挂 `batches` 批行,到达行(`arrivals.batch_id`)与源态变迁行(`source_states.batch_id`)外键绑同一批号,`PRAGMA foreign_keys=ON` 强制;任一侧缺失,全事务回滚,两侧拒收,库态保持撕裂前。
- 甲路径(入库前预查源输出态版本已变则拒绝到达写入、到达行不增)**不启用**,不得与乙路径混用。

## 半成锁与争用

- 调度与入库同时写同一源:写路须先占半成锁(按源名互斥,try 取锁,整个写事务持锁)。
- 后交不占锁、不落库,只记 `half_success_events(kind='半成争用')` 留痕,并以 409 回绝。

## 偏离

- 写路径偏离本说明(未同批绑定、未占半成锁)即拒绝,记 `half_success_events(kind='半成偏了')`;库触发器兜底,未绑批号的到达/源态/补齐写直接 ABORT。

## 五处对齐

水位卡片(`/api/summary`)、源目录(`/api/sources`)、到达列表(`/api/arrivals`)、详情(`/api/sources/{name}/detail`)、对账账册(`/api/ledger`)同出一批,禁止撕裂。

## 杂项

- 半成入口挂时限台入库页(到达登记页),不另起半成台;入库页标注:**外键同批绑定 生效 / 预查拒写 未启用**。
- 口令沿用本仓半成侧:admin / 123456(Bearer),不另设账号。
- 库文件放在半成仓区:`data/app.db`,不另置库文件。

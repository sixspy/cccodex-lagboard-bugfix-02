# 源到达SLA

> 遵守 `ops/底座生成前必读_效率与技术栈.md`。FastAPI + Vue 3 + SQLite，交付须 docker compose 一键起；库用 SQLite，不挂外置 Postgres。  
> **禁止同构换皮**：本仓主链路、表结构、接口与页面均独立，不得与其它仓共用同一套 `/api/items` 壳。

## 骨架一句话

多源到达时钟对照 SLA 分级，超限则冻结或降级输出，补齐后恢复并对账

## 为何能出多题

源时钟 vs 摄入时钟、分级处罚、降级可读不可写、补齐解冻

## 半成切断(已封存)

到达与源态同败同成,走乙路径(同批事务号外键绑定),见 `docs/半成切断说明.md`(2026-11-19 封存,当日不得更换)。入库页标注生效口径;调度与入库抢写同一源占半成锁,后交只记半成争用(`GET /api/half-success/events`)。五处对齐:水位卡片 `/api/summary`、源目录 `/api/sources`、到达列表 `/api/arrivals`、详情 `/api/sources/{name}/detail`、对账账册 `/api/ledger`。

## 避开

别做成纯监控大盘；须有写路径与状态机

## 互斥切口候选

- 超SLA冻结 vs 降级只读
- 补齐整源解冻 vs 按业务日窗口解冻
- 只认源时钟 vs 双时钟取严

## 启动（一键）

`powershell
cd projects/06-lagboard
docker compose up -d --build
`

浏览器：http://127.0.0.1:10827/  
健康检查：GET http://127.0.0.1:10827/api/health

本机开发（可选）：

`powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 10603
python -m pytest -q
`
